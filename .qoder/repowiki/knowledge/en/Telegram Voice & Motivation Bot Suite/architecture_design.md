The repository contains two self-contained bot entry points (`bot.py` and `voice_logger_bot.py`) that share no Python imports but converge on identical external tooling and data conventions. Both bots use `python-telegram-bot`'s `Application` with polling, register command/message handlers, persist a `chat_id.txt` in `data/`, store raw audio as timestamped `.ogg` files converted to 16 kHz mono `.wav` via `ffmpeg`, and transcribe through the same `whisper-cli.exe` binary with `-otxt -of` flags producing paired `.txt` transcripts. `bot.py` is the lightweight daily reminder + transcript logger; `voice_logger_bot.py` extends the pattern by launching a local `llama-server` process (managed via `subprocess.Popen` + `atexit`), calling its OpenAI-compatible `/v1/chat/completions` endpoint for text replies and vision-based trade-image extraction, then persisting trades to `trades.csv` with FIFO P&L computation and watchlist-driven price lookups via `yfinance`. Each bot owns its own `DATA_DIR = Path(__file__).parent / "data"` layout, so they can run concurrently without file collisions beyond the shared `audio/` subdirectory.
