Flat data directory with three logical layers: (1) `chat_id.txt` holds the single Telegram chat identifier used as the bot's destination; (2) `voice_log.jsonl` is an append-only event log where each line is a JSON object recording timestamp, source (`voice`), input text, reply text, and the associated `audio_file`; (3) `audio/` stores the raw media files — for every recorded session there are triplets of `.ogg`, `.wav`, and a matching `.txt` transcript file named by the UTC timestamp (`YYYYMMDD_HHMMSS`). The module has no code; it is consumed by the bot application which writes new entries to `voice_log.jsonl` and drops corresponding audio+transcript pairs into `audio/` on each interaction.
