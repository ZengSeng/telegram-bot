This repository contains two Python-based Telegram bots (bot.py and voice_logger_bot.py) that process voice messages, transcribe audio using whisper.cpp, and log data to JSONL/CSV files under the data/ directory. There is no frontend code, CSS, HTML, or any UI styling system present in this repository. The bots interact with users exclusively through the Telegram platform's native interface, so there are no design tokens, component libraries, themes, or responsive styles to document.
